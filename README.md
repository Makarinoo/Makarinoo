# Makarin0

Étudiant en Bachelor Cybersécurité à l'EPITA (2025-2028), orienté sécurité des
systèmes d'information.

Je m'intéresse surtout à ce qui se passe quand un système casse : pourquoi il
casse, comment on le remet debout, et comment on aurait pu le voir venir. D'où un
mélange de sécurité offensive web, d'administration Linux et de détection.

**Je recherche une alternance à partir de septembre 2027** (2 semaines en
entreprise / 1 semaine en cours), sur Paris.
